# EZZO Studio Dev — Roadmap de Funcionalidades & Histórico de Versões

> Estado Atual: **v1.0.9 — Release Completa (Electron + React + TypeScript + Socket.io + CodeMirror 6 + Xterm.js)**

---

## 📅 Histórico de Releases Executadas

### 🟢 Versão 1.0.9 (Atual)
- [x] **Rebranding EZZO Studio Dev** com distintivo `#22c55e`
- [x] **Controlo Nativo de Janela Electron** (Minimizar, Maximizar/Restaurar, Fechar)
- [x] **Barra Superior de Ações Rápidas** (Open Folder, Save All, Hide Terminal, Hide Sidebar, Split Editor, VS Code)
- [x] **Ordenação do File Explorer**: Pastas primeiro (A-Z) seguidas de ficheiros (A-Z)
- [x] **Vetorização Oficial de Ícones por Extensão** (`.ts`, `.tsx`, `.js`, `.html`, `.css`, `.json`, `.py`, `.md`, `.env`, `package.json`, etc.)
- [x] **Criação Direcionada por Seleção**: Diálogo popover flutuante não obstrutivo direcionado à pasta selecionada
- [x] **EZZO Project Analytics**:
  - Resumo de ficheiros, linhas de código e tamanho total
  - Badges de linguagem e barra visual de distribuição proporcional
  - Instalação Real de Dependências (`npm.cmd install`) com barra de progresso (0-100%) e Notificações Desktop do SO
  - Ficheiros recentes e TODOs clicáveis com salto automático para linha
- [x] **Editor de Imagens**: Crop com overlay, resize com bloqueio de proporção e presets de dimensão
- [x] **HTML Live Preview**: Visualização ao vivo de páginas HTML
- [x] **Terminal Avançado**: `Ctrl+C` (Copiar), `Ctrl+V` (Colar), `convertEol: true` (fim de erros de alinhamento em escada), suporte multi-shell e split view
